# onStageInstanceUpdate

Fires when a stage instance has its topic or privacy level changed. Requires the GUILDS intent. Stage fields are read with `Zoption{key}`.

## When it fires

Stage details change


## Available Context Variables

| Variable | Description |
| :--- | :--- |
| author_id | Empty |
| username | Empty |
| channel_id | Stage channel ID |
| guild_id | Guild ID |
| message | Empty. Zoption keys: topic, privacy (e.g. GuildOnly), discoverable |
| trigger_message_id | Stage instance ID |
