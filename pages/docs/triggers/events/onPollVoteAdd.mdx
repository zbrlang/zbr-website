# onPollVoteAdd

Fires when a user votes on a poll. Requires the GUILD_MESSAGE_POLLS intent. Poll fields are read with `Zoption{key}`.

## When it fires

A vote is added to a poll


## Available Context Variables

| Variable | Description |
| :--- | :--- |
| author_id | User ID who voted |
| username | Empty |
| channel_id | Channel ID of the poll |
| guild_id | Guild ID (if applicable) |
| message | Empty. Zoption keys: messageID, answerID |
| trigger_message_id | Poll message ID |
