# ZregexCapture

Returns the capture group at the given index from the first match of the pattern. Index 0 is the whole match, 1 and above are capture groups. Returns an empty string when the pattern does not match.

## Syntax

```zbr
ZregexCapture{text;pattern;index}
```


## Arguments

| Name | Type | Required | Default |
| :--- | :--- | :--- | :--- |
| text | string | Yes | - |
| pattern | string | Yes | - |
| index | number | Yes | - |



## Example

```zbr
ZregexCapture{warned by <@123> : spamming;warned by <@(\d+)> : (.+);1}
```
