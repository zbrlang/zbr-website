# ZaiExtractCtx

Extracts specific information from the current Discord context based on the instruction. Returns 'N/A' if not found.

## Syntax

```zbr
ZaiExtractCtx{apiKey;instruction;model?}
```


## Arguments

| Name | Type | Required | Default |
| :--- | :--- | :--- | :--- |
| apiKey | string | Yes | - |
| instruction | string | Yes | - |
| model | string | No | gemini-2.5-flash-lite |



## Example

```zbr
ZaiExtractCtx{AIza...;all mentioned usernames}
```
