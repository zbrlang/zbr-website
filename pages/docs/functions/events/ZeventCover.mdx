# ZeventCover

Gets or sets the cover image URL for a scheduled event.

## Syntax

```zbr
ZeventCover{eventID;imageURL?}
```


## Arguments

| Name | Type | Required | Default |
| :--- | :--- | :--- | :--- |
| eventID | snowflake | Yes | - |
| imageURL | url | No | - |



## Example

```zbr
ZeventCover{1234567890123456789;https://example.com/cover.png}
```
