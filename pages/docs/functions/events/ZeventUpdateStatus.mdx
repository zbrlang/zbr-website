# ZeventUpdateStatus

Updates the status of a scheduled event.

## Syntax

```zbr
ZeventUpdateStatus{eventID;status}
```


## Arguments

| Name | Type | Required | Default |
| :--- | :--- | :--- | :--- |
| eventID | snowflake | Yes | - |
| status | integer | Yes | - |



## Example

```zbr
ZeventUpdateStatus{1234567890123456789;2}
```
