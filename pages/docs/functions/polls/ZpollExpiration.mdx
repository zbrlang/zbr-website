# ZpollExpiration

Gets or sets the poll's end timestamp.

## Syntax

```zbr
ZpollExpiration{pollID;endTime?}
```


## Arguments

| Name | Type | Required | Default |
| :--- | :--- | :--- | :--- |
| pollID | snowflake | Yes | - |
| endTime | integer | No | - |



## Example

```zbr
ZpollExpiration{1234567890123456789;1721234567}
```
